Life Cycle

Spring container memiliki alur hidup untuk setiap bean yang dikelolaanya.

Siklus ini mencakup beberapa tahapan penting terutama:

1. Inisialisasi
Ketika Spring Container membuat bean, semua dependecy (melalui constructor atau setter injection) akan dimasukkan terlebih dahulu. Setelah semua dependecy tersedia, Spring akan memberitahu bean bahwa ia sudah siap digunakan. Bean bisa melakukan proses inisialisasi tambahan, misalnya membuka koneksi atau melakukan validasi konfigurasi internal.

2. Penggunaan
Setelah proses inisialisasi, bean bisa digunakan oleh komponen lain dalam aplikasi Spring.

3. Destruksi (Penghancuran)
Saat aplikasi Spring akan dimatikan (bisa saat context ditutup). Spring akan memberitahu setiap bean bahwa ia akan dihancurkan. Pada tahap ini, bean dapat melakukan "proses cleanup", seperti menutup koneksi database, melepas resource, atau menyimpan data akhir.


Cara Menangani Life Cycle
Spring menyediakan beberapa cara untuk mengatur logika pada tahap awal dan akhir siklus hidup bean,

1. Dengan method khusus
Method yang digunakan adalah anotasi @PostConstruct (untuk inisialisasi) dan @PreDestroy (untuk cleanup).

contoh penggunaan

@PostConstruct
public void init() {
	// kode inisialisasi
}

@PreDestroy
public void destroy() {
	// kode cleanup
}

2. Mengimplementasikan interface (Life Cycle Callback),
InitializingBean: method afterPropertiesSet()
DisposableBean: method destroy()

3. Mengatur secara eksplisit di konfigurasi.
@Bean(initMethod = "...", destroyMethod = "...");
